Privacy Policy

Effective date: October 6, 2026. App: Python code (inosuke.code.python).

Python code does not collect, store on a server, or share your personal data. There are no accounts, no ads and no analytics.

What stays on your phone

Your code files, project folders, settings, themes and open tabs are saved only on your device. The app does not upload them anywhere.

Permissions we ask for

  • Internet. Used when you install libraries with pip, which downloads packages from the Python Package Index (pypi.org). Programs you write yourself can also use the internet if your code asks for it.
  • Files and storage (all files access). Used so you can open, edit and save Python files and project folders on your phone, and so scripts can read and write files next to them. The app only works with the files and folders you choose or create. It does not scan or read anything else.

Your own code

Scripts you run have the same access as the app. If your script sends data over the internet, that is done by your code, and you are responsible for it.

Third parties

The app has no advertising or analytics tools. When you install or update the app through Google Play, Google handles that under its own Privacy Policy. Packages you install with pip come from pypi.org and the authors of those packages.

Children

The app is a coding tool for a general audience. Because it collects no personal data, there is no child data to collect.

Deleting your data

Uninstalling the app removes its settings and its private data. Python files saved in shared storage (for example the PythonSSC folder) stay on your phone until you delete them yourself in a file manager.

Changes to this policy

If this policy changes, the new version and a new effective date will be posted on this page.

Contact

Questions about privacy? Message the developer on Telegram or open an issue on GitHub.
